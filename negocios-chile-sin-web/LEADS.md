## Cómo usar estas demos para vender

1. **Abre la demo** del negocio (`index.html` es el catálogo con las 30).
2. **Contacta al negocio** por WhatsApp o teléfono con un mensaje corto, por ejemplo:
   > "Hola, soy [nombre]. Vi que [negocio] atiende por Facebook y les preparé una página web de muestra para que la vean sin compromiso: [enlace/pantallazo]. Si les gusta, la dejo funcionando con su dominio propio (.cl) en 48 horas. ¿Se la muestro?"
3. **Ajusta la demo** antes de enviarla: fotos reales del negocio, horarios y precios los entrega el dueño.
4. Para publicarla con dominio propio basta un hosting estático (Netlify, Vercel, GitHub Pages) + dominio NIC Chile.

## Regenerar los sitios

```bash
python3 generar_sitios.py
```

Edita `data/negocios.json` para corregir datos o agregar negocios; el diseño por rubro está en `generar_sitios.py` (`RUBROS`).

## Notas éticas y legales

- Los datos provienen de información publicada por los propios negocios (Facebook, directorios).
- Cada demo lleva un aviso visible de "sitio de demostración, no oficial" para no suplantar al negocio.
- No publiques la demo en un dominio que sugiera ser el sitio oficial del negocio sin su autorización.
- Ley 19.628 (protección de datos, Chile): usa los contactos solo para esta propuesta comercial directa y elimina los datos si el negocio lo pide.
